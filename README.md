# Vibe Coding Guide

A personal collection of useful **vibe-coding** resources — articles, notes, summaries, and references gathered from various sources.

The goal is to keep a single, searchable place for the ideas, tools, and workflows that make AI-assisted coding actually work in practice.

## Structure

```
.
├── README.md          # this file
└── notes/             # individual notes, summaries, and references
    └── *.md
```

Each entry in `notes/` is a standalone file. Add a short front-matter block (title, source, date) to keep things greppable.

# Vibe Coding 指南

个人收集的 **vibe-coding** 相关资料合集 —— 文章、笔记、摘要与参考链接，来源包括个人总结和外部资料。

目的：把那些让 AI 辅助编程真正在实践中起作用的思路、工具和工作流，集中放在一个可检索的地方。

## 目录结构

```
.
├── README.md          # 本文件
└── notes/             # 单篇笔记、摘要、参考
    └── *.md
```

`notes/` 下每个文件独立成篇。建议在文件顶部加一段 front-matter（标题、来源、日期），方便用 `grep` 检索。
