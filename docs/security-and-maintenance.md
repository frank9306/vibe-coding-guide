# 安全与维护

## 权限边界

Prompt 说明何时做某事，sandbox、审批、hook 和 CI 强制边界。删除或覆盖、清理数据、migration、认证修改、依赖安装、Git 写操作、发布以及向第三方发送私有数据，默认需要明确授权。

## 第三方供应链

Skill、Plugin 和 MCP 可能执行本机命令并读取工作区。固定版本、审查更新、限制权限，避免执行来源不明的 pipe-to-shell 安装命令。

## 自主循环停止条件

以下情况必须停止并报告：

- 连续两个检查点没有新证据或进展。
- 相同错误连续出现三次。
- 达到 token、费用或运行时间预算。
- 缺少凭据、网络不可用、合并冲突等外部阻塞。

停止条件应写进项目规则或启动脚本，不只存在于一次聊天。

## 记忆治理

- 密钥、客户信息和私有路径不写入长期记忆。
- 处理不可信内容时关闭或限制记忆写入。
- 项目事实以代码、测试和当前文档为准。
- 记忆系统必须允许查看、删除和禁用。

## 月度检查

- 全局规则是否混入项目内容。
- 项目命令是否仍能执行。
- Skill 来源是否固定且仍被使用。
- MCP、Plugin、Connector 是否可连接。
- 凭据权限是否最小。
- hooks 是否真实触发且没有误拦截。
- 自主循环是否有预算和停止条件。
- 文档是否重复、冲突或失效。
